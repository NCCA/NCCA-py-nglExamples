# ChangingVAO

![](ChangingVAO.png)

This demos shows how we can change the VertexArrayObject dynamically by adding or removing vertices. In this case each frame we generate a number of random lines and render them each frame.

## References

- [OpenGL Wiki — Buffer Object Streaming](https://www.khronos.org/opengl/wiki/Buffer_Object_Streaming) — techniques for buffers whose contents change every frame.
- [OpenGL Wiki — Vertex Specification](https://www.khronos.org/opengl/wiki/Vertex_Specification) — VAO/VBO fundamentals.
