# ExtendedVAOFactory

This demo shows how to create and register your own custom VAO to the factory. This allows you to create custom VAOs that can be used in your application. In this case we create a custom VAO that has different draw and index functions.

## References

- [Factory Method pattern (Refactoring.Guru)](https://refactoring.guru/design-patterns/factory-method) — the registration/creation pattern the VAO factory uses.
- [OpenGL Wiki — Vertex Specification](https://www.khronos.org/opengl/wiki/Vertex_Specification) — what the custom VAO wraps.
