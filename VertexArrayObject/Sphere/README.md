# Sphere

![](Sphere.png)

This shows how to create a sphere algorithmically and add the vertices, normals, and uv's to a SimpleVAO and render with a texture.

## References

- [Creating a Sphere (songho.ca)](https://www.songho.ca/opengl/gl_sphere.html) — the stacks/sectors parametric sphere with normals and UVs, as generated here.
- [LearnOpenGL — Textures](https://learnopengl.com/Getting-started/Textures) — applying the texture via the generated UVs.
