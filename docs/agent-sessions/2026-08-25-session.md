# 2026-08-25 -- MuJoCoNGL demo

## Goal

Port the C++ [BulletNGL](https://github.com/NCCA/BulletNGL) demo to PyNGL, using
MuJoCo for the physics rather than Bullet. (pybullet does not build on this
machine, which is what `err.txt` in the root was left over from.)

## Decisions taken

- Spawning: implement **both** strategies (MjSpec recompile and a pre-allocated
  pool) behind one facade, switchable at runtime, since MuJoCo has no `addBody`.
- Meshes: copy teapot and apple, high-res and low-res, from NGL9Demos (~6MB).
- UI: keep every C++ key binding, add a panel for the MuJoCo-only parameters
  (integrator, timestep, substeps, solver iterations, gravity, spawn cost).

## Files changed

- `MuJoCoNGL/collision_shapes.py` -- shape catalogue, cone hull generator, OBJ
  hull loader via PyNGL's `Obj`
- `MuJoCoNGL/physics_world.py` -- `PhysicsWorld` facade, `RecompileWorld`,
  `PoolWorld`
- `MuJoCoNGL/scene.py` -- drawing only, no MuJoCo
- `MuJoCoNGL/main.py` -- window, panel, key bindings
- `MuJoCoNGL/tests/test_physics_world.py` -- 37 headless tests
- `MuJoCoNGL/README.md`, `MuJoCoNGL/MuJoCoNGL.png`, `MuJoCoNGL/models/`
- `README.md` -- row added under Collision Detection
- `.gitignore` -- `MUJOCO_LOG.TXT`

## What cost time

- `body_gravcomp` writes at runtime are silently ignored unless at least one
  body asked for gravcomp when the model was compiled -- `ngravcomp` gates the
  whole calculation. Parked pool bodies drifted until this was set in the spec.
- A MuJoCo plane is an infinite half-space, so parking bodies below it means
  deep penetration and the solver launches them. The pool parks above.
- `spec.recompile` leaves `xpos`/`xmat` stale; without `mj_forward` a body drawn
  before the next step renders at the origin. Two tests caught this.
- MuJoCo moves mesh vertices into the principal inertia frame on compile, so
  both `mesh_pos` and `mesh_quat` are non-identity and the drawn OBJ needs the
  inverse folded in.
- `make_cone(nedge, radius)` does not take a height and does not produce the
  radius asked for; the cone is generated by hand instead.
- `Prims` comes from `ncca.ngl`, not `ncca.ngl.opengl`.
- NGL's stock unit cube is named `cube`, not `box`.
