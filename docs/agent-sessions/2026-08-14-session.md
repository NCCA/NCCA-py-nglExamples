# 2026-08-14 session: MathNodeEditor main window

## Goal

Make `MathNodeEditor/main.py` follow the other PyNGL demos by owning the
application `MainWindow` and Qt entry point. Keep `node_editor.py` concerned
with the editor itself rather than application startup.

  main window and application entry point
