# Later session — normal-matrix fix

## Goal

Fix `hdri_demo.py` showing inconsistent albedo (white patches on a yellow
metal teapot) and upside-down reflections once the camera rotates.

## Root cause

`PBR.wgsl` lights entirely in world space, but
`_write_teapot_transform_uniforms` built the normal matrix from
`model_view`, putting the normals in view space. The `FirstPersonCamera`
constructor leaves yaw/pitch at their defaults (identity view rotation),
which hid the bug at startup; any camera rotation made `dot(N, V)` collapse
to grazing over parts of the mesh (Fresnel whiting out the albedo) and
flipped the reflection vector.

Note: `PBR/HDRI/HDRIWebGPU.py` and the OpenGL `PBR/HDRI/main.py` share the
same pattern (normal matrix from MV, world-space shader) — the latent bug
exists there too, hidden by their near-static cameras. Not fixed in this
session.

## Files changed

- `PBR/HDRIBaker/hdri_demo.py` — normal matrix now from the model alone
- `PBR/HDRIBaker/tests/test_hdri_demo.py` — new regression test driving the
  real packing method with a mouse-dragged camera

## Commands run

- `uv run pytest PBR/HDRIBaker/tests/` → 34 passed
- `uv run ruff check` / `ruff format --check` → clean
- `uv run hdri_demo.py --smoketest 600` → `SMOKETEST OK`

Committed as `b904513` on `agent/hdri-ibl-baker`.

# Later session — upside-down default maps, and the same fix family-wide

## Goal

1. The demo's default environment rendered upside down: the bundled
   `ibl_maps.npz` predated the pole-swap bake fix, and that fix
   (`agent/hdri-cube-orientation`) had never been merged into `Version1.0`.
2. Fix the same world-space/normal-matrix bug across the rest of the PBR
   demo family.

## What happened

- Verified the bundled maps were pole-swapped by dumping the env cube as a
  cross image (+Y showed the floor). Merged `agent/hdri-cube-orientation`
  (bake fix + rebaked `ibl_maps.npz`) into `agent/hdri-ibl-baker`, verified
  the cross now has the ceiling up, then merged into `Version1.0`.
- Swept `PBR/` for the MV-derived normal matrix feeding world-space
  shaders: six demos had it — `HDRI/main.py`, `HDRI/HDRIWebGPU.py`,
  `IBL/main.py`, `SimplePBR/main.py`, `PBRTexture/main.py`,
  `PBRTexture/PBRTextureWebGPU.py`. All now use the inverse transpose of
  the model alone, each with a regression test (stand-in scene + stubbed
  ShaderLib or device queue, camera rotated so the view matters). IBL's
  grid loop moved out of `paintGL` into `_draw_sphere_grid` to make it
  testable without a GL context.
