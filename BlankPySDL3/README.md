# BlankPySDL3

![](BlankPySDL3.png)

This demo shows how to create a simple PySDL3 application and OpenGL Context. This demo can be used as a starting point for creating your own PySDL3 applications.

It mirrors the functionality of the PySide application with keyboard and mouse input for simple interaction.

## References

- [PySDL3 documentation](https://pysdl3.readthedocs.io/) — the Python SDL3 binding used for windowing and input.
- [SDL3 Wiki](https://wiki.libsdl.org/SDL3/FrontPage) — the underlying SDL3 API, including `SDL_GL_CreateContext` and the event loop.
- [PyOpenGL](https://pyopengl.sourceforge.net/) — the OpenGL binding used for rendering.
