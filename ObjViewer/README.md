# ObjViewer

![](ObjDemo.png)

This demo shows how to use the PyNGL Obj class to load and display obj files.

This demo loads the obj and an optional texture file which is then converted into a Vertex Array Object (VAO) for rendering.

## References

- [Wavefront OBJ file format (Paul Bourke)](https://paulbourke.net/dataformats/obj/) — the OBJ specification parsed by `ncca.ngl.Obj`.
- [Wavefront .obj — Wikipedia](https://en.wikipedia.org/wiki/Wavefront_.obj_file) — format overview including MTL and texture-coordinate conventions.
- [LearnOpenGL — Mesh](https://learnopengl.com/Model-Loading/Mesh) — turning loaded vertex/normal/UV data into a renderable VAO.
