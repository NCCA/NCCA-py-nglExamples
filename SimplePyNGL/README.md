# SimplePyNGL Examples

![](PySDL3NGLDemo.png)

These examples are small complete demos showing how to load a PBR shader and use the built in shaders and primitives.

## References

- [PyNGL documentation](https://ncca.github.io/PyNGL/) — `ShaderLib`, `DefaultShader` and the built-in primitives used here.
- [LearnOpenGL — PBR Lighting](https://learnopengl.com/PBR/Lighting) — the PBR shading model behind the default PBR shader.
