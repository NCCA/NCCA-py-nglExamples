## Blank WebGPU

![](BlankWebGPU.png)

A bare bones WebGPU demo used as a starting point for other demos. As WebGPU needs a pipeline to even clear the screen this demo draws the simplest triangle geometry so all the relevant elements of the code are in place to build more complex demos.

## References

- [WebGPU Fundamentals](https://webgpufundamentals.org/webgpu/lessons/webgpu-fundamentals.html) — the minimal triangle + pipeline setup this demo mirrors.
- [WebGPU Specification](https://www.w3.org/TR/webgpu/) and [WGSL Specification](https://www.w3.org/TR/WGSL/) — the W3C standards.
- [wgpu-py documentation](https://wgpu-py.readthedocs.io/) — the Python WebGPU implementation used here.
