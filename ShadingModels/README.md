## Shading Models

This tool is designed to demonstrate various shading models in computer graphics and is used as part of my lectures.


The tool loads in a json file containing the shader description and material properties for each model.

## References

- B. T. Phong, "Illumination for Computer Generated Pictures", CACM 1975 — [ACM](https://dl.acm.org/doi/10.1145/360825.360839) — the ambient/diffuse/specular model.
- J. F. Blinn, "Models of Light Reflection for Computer Synthesized Pictures", SIGGRAPH 1977 — [ACM](https://dl.acm.org/doi/10.1145/965141.563893) — the half-vector modification (Blinn-Phong).
- [LearnOpenGL — Advanced Lighting](https://learnopengl.com/Advanced-Lighting/Advanced-Lighting) — Phong vs Blinn-Phong compared in GLSL.
- [LearnOpenGL — Basic Lighting](https://learnopengl.com/Lighting/Basic-Lighting) — the diffuse/specular components each model builds on.
