# ColourObj

Loads an OBJ variant where each vertex line carries a baked RGB colour
(`x y z r g b`) and renders it with per-vertex colour, no lighting.

## Controls
Left-drag : orbit, Right-drag : pan, Wheel : zoom, `space` : reset

## References

- [Wavefront OBJ file format (Paul Bourke)](https://paulbourke.net/dataformats/obj/) — the base OBJ specification.
- [Wavefront .obj — Wikipedia](https://en.wikipedia.org/wiki/Wavefront_.obj_file) — including the unofficial per-vertex colour extension (`x y z r g b`) used by this demo.
